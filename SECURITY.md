# Security Policy

## Reporting a vulnerability

Do not open a public issue for security problems.

Use [private vulnerability reporting](https://github.com/prosenstrom/pycaruna/security/advisories/new) on this repository.

## Supported versions

Only the latest release of this fork is supported.

## Credentials

This client sends a Caruna+ email and password and holds a session token. Do not commit credentials, tokens, or captured API responses that contain personal data.
